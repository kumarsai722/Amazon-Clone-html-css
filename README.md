# Amazon-Clone-html-css
Amazon Clone website built using HTML and CSS with a responsive e-commerce UI.
A frontend Amazon Clone website developed using **HTML5 and CSS3**, designed to replicate the layout and user interface of an e-commerce platform.

Live Demo:http://127.0.0.1:3000/amazon_clone.html?vscode-livepreview=true

## 🚀 Features

* Amazon-inspired navigation bar and header
* Search bar and category navigation
* Product cards and product sections
* Promotional/banner sections
* Responsive layout
* Footer with multiple navigation sections
* Clean and structured HTML/CSS implementation

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* Responsive Web Design
